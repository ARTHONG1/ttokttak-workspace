똑딱작업실 0.16.3은 **바탕이 된 다른 프로젝트의 이름을 앱과 저장소에서 모두 걷어 낸 버전**입니다. 앱 화면, 터미널 명령어, AI 에이전트 연결, 설치 안내, 도움말에 똑딱작업실의 이름만 남았고, 기존 설정은 처음 실행할 때 자동으로 옮겨집니다.

## 바뀐 것

- **이름 정리**: 앱의 모든 화면 문구(21개 언어), 도움말, 설치 스크립트, README와 개발 문서에서 바탕 프로젝트의 이름과 주소를 지웠습니다. 앱 아이콘은 0.16.2부터 ACE 연구회 토끼입니다.
- **터미널 명령어 `ttokttak`**: AI 에이전트가 쓰는 명령어와 MCP 서버 이름이 `ttokttak`, 문서 작업 스킬 이름도 `ttokttak`으로 바뀌었습니다. 설정 폴더는 `~/.ttokttak`입니다.
- **기존 설정 자동 이전**: 이전 버전을 쓰던 PC에서는 첫 실행 때 앱이 예전 설정 폴더와 내가 설치한 스킬, Claude Code·Codex·Cursor 등에 등록된 MCP 서버와 스킬, 터미널 명령어 연결을 새 이름으로 옮깁니다. 이 앱이 만든 것만 옮기고, 다른 프로그램의 설정은 건드리지 않습니다.

## 고친 것

- 내장 AI 모델이 들어 있지 않은 설치본(Windows·Intel Mac·웹 체험판)에서는 AI 선택 목록과 설정에 "내장 AI"가 보이지 않습니다. 예전에는 쓸 수 없는 항목이 목록에 나타났습니다.
- 설정의 고급 AI 항목이 열쇠(API 키)를 받지 않는 내장 AI 대신 첫 번째 API 키 항목으로 열립니다.
- 설치 스크립트가 이 PC용 파일이 없는 버전을 만나면, 이 PC에 맞는 가장 최근 버전을 자동으로 고릅니다.

## 현재 범위와 다음 단계

- 내장 AI 모델(Qwen3.5-2B, 약 1.28GB)은 **Apple Silicon Mac 설치 파일에만** 들어 있습니다. Windows와 Intel Mac은 [v0.16.1](https://github.com/ARTHONG1/ttokttak-workspace/releases/tag/v0.16.1)을 그대로 쓰며, 설치 스크립트가 알맞은 버전을 고릅니다.
- 문서 편집 특화 모델은 자체 학습 중입니다. 실제 문서 저장·재열기 검증을 통과한 뒤 다음 버전에 넣습니다.
- 예전 `ieumoffice` 명령어로 직접 만든 스크립트가 있다면 `ttokttak`으로 바꿔 주세요.

## 설치

Apple Silicon Mac 사용자는 `arm64`가 적힌 설치 파일을 고르세요. 서명·공증되지 않은 베타 설치본이라 처음 열 때 macOS 보안 확인이 필요할 수 있습니다.
