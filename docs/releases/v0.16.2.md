똑딱작업실 0.16.2는 **Apple Silicon Mac용 설치 파일에 자체 실행형 AI 모델을 포함한 첫 버전**입니다. 문서에 간단한 수정을 지시하거나 초안을 만들 때 인터넷 연결이나 외부 AI 구독 없이 시작할 수 있습니다.

## 새로 들어간 것

- **내장형 AI**: 공개 모델 Qwen3.5-2B(Q4_K_M, 약 1.28GB)와 llama.cpp를 Apple Silicon Mac용 앱에 포함했습니다. 새로 설치한 환경에서는 내장 AI가 기본으로 선택됩니다.
- **로컬 실행**: 모델은 PC 내부의 `127.0.0.1`에서 실행됩니다. 앱이 임시 인증 키와 포트를 관리하고 종료 시 실행기를 정리합니다.
- **AI 문서 작업 확대**: 한글·워드의 지정 문구 수정과 문서 초안, 엑셀·PPT·PDF의 일부 수정 흐름을 내장 모델 및 각 편집기 도구와 연결했습니다. 변경 결과와 저장 여부를 확인할 수 있도록 테스트를 추가했습니다.
- **AI 선택 설정**: 기존 Codex·Claude 연결을 유지하면서 내장 AI를 선택할 수 있도록 설정과 첫 실행 흐름을 정리했습니다.

## 고친 것

- Word·Excel 등 문서 편집 결과를 적용하고 확인하는 경로를 보완했습니다.
- 로컬 모델의 잘못된 수정 지시나 확인되지 않은 완료 응답을 막기 위한 검사와 회귀 테스트를 추가했습니다.
- GitHub 릴리스 설명을 저장소 첫 화면과 업데이트 기록에 자동으로 반영하는 배포 작업을 추가했습니다.

## 현재 범위와 다음 단계

- **내장 모델 포함 및 실행 검증: macOS Apple Silicon(arm64)**. Windows·Intel Mac·웹 체험판은 이번 내장 모델 적용 대상이 아닙니다. 기존 AI 연결 기능은 그대로 쓸 수 있습니다.
- 지금 탑재한 것은 공개 양자화 모델입니다. **학교·사무 문서 전용 추가 학습(SFT·LoRA)은 아직 진행·검증을 마치지 않았으며**, 다음 개발 단계입니다.
- 2B급 소형 모델의 초안·편집 결과는 사람의 검토가 필요합니다. 복잡한 문서에서는 답변이 느리거나 지시를 정확히 수행하지 못할 수 있습니다.
- 모델의 최초 실행에는 메모리와 시간이 필요합니다. 별도의 API 요금은 발생하지 않지만, 설정에서 외부 AI를 고르면 해당 서비스 정책이 적용됩니다.

## 설치

Apple Silicon Mac 사용자는 아래 설치 파일 중 `arm64`가 적힌 파일을 선택하세요. 모델을 포함하므로 종전 버전보다 다운로드 크기가 큽니다. 서명·공증되지 않은 베타 설치본이며, 일반적인 보안 확인이 필요할 수 있습니다.
