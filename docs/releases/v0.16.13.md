똑딱작업실 0.16.13은 **설치판(Mac·Windows)이 크롬 확장 프로그램 없이 K-에듀파인과 나이스에 직접 채우도록 바꾸고, 똑딱정리에 문서를 끌어다 놓으면 편집기로 열리던 문제를 고친 업데이트**입니다.

## 바뀐 것

- **품의서 생성 → K-에듀파인, 생기부 → 나이스 직접 채우기**: 설치판에서 [K-에듀파인으로 보내기]나 [나이스로 보내기]를 누르면 앱이 똑딱작업실 전용 Chrome(또는 Edge) 창을 엽니다. 그 창에서 업무포털에 로그인하고 품의등록 화면이나 나이스 입력 화면(첫 학생 줄 선택)을 연 뒤 앱에서 한 번 더 누르면, 앱이 직접 채우고 들어간 값을 다시 읽어 맞는지 확인합니다. 똑딱작업실 확장 프로그램은 필요 없습니다.
  - AI는 이 과정에 끼지 않습니다. [저장]과 결재는 채운 내용을 확인한 뒤 선생님이 직접 누릅니다.
  - 학생 이름이 다르거나, 칸에 이미 다른 글이 있거나, 채울 화면이 두 개 이상 열려 있으면 아무것도 덮어쓰지 않고 멈춥니다. 중간에 멈추면 멈춘 학생 줄을 골라 다시 보내면 거기서부터 이어서 채웁니다.
  - K-에듀파인에서 품목 입력이 실패하면 이번에 추가한 줄을 되돌립니다.
  - 전용 창은 개인 Chrome과 따로 쓰므로, 처음 한 번은 전용 창에서 로그인해야 합니다. Chrome이나 Edge 가운데 하나가 설치돼 있어야 합니다.
- 예전 버전이 확장 프로그램과 연결하려고 크롬·엣지에 남긴 등록은 앱이 켜질 때(Windows는 설치할 때도) 지웁니다.
- 웹판은 지금처럼 똑딱작업실 크롬 확장으로 보냅니다.

## 고친 것

- **똑딱정리·문서 변환·똑딱서명에 문서를 끌어다 놓으면** 그 화면에 올라가지 않고 문서 편집기로 열리던 문제를 고쳤습니다. 이제 놓은 문서가 그 화면에 바로 올라갑니다. 똑딱정리는 여러 개를 한 번에 놓을 수 있고, 문서를 올린 뒤에 더 놓으면 합치기 목록에 붙습니다(설치판·웹판 모두).
- 똑딱정리에서 문서를 하나 올린 뒤 **[○○ 문서 더 올리기]**로 같은 종류 문서를 더해 합칠 수 있습니다. 전에는 [다른 문서 올리기]를 누르면 앞 문서가 바뀌어 버렸습니다(이 버튼은 [다른 문서로 바꾸기]로 이름을 바꿨습니다).

## 알려진 한계

- 직접 채우기는 가짜 나이스·K-에듀파인 화면으로 시험했습니다. 교육청마다 다른 업무포털 화면, 인증서 보안 프로그램, Windows 결재창에서는 아직 확인하지 못했습니다. 막히는 화면이 있으면 알려 주세요.
- AI 에이전트(Codex·Claude 연결)에서 품의를 확장 프로그램으로 넘기던 도구는 뺐습니다. 품의는 똑딱업무의 품의서 생성에서 보내 주세요.

## 설치

Apple Silicon Mac은 `arm64`, Intel Mac은 `x64`가 적힌 DMG, Windows는 `Setup` EXE를 고르세요. 내장 똑딱AI는 Apple Silicon Mac과 Windows(64비트) 설치 파일에 들어 있습니다. 이미 설치했다면 앱의 **업데이트 확인**으로 받을 수 있습니다.
