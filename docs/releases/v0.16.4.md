똑딱작업실 0.16.4는 **내장 AI 모델을 문서 편집용으로 추가 학습한 버전으로 바꾼 업데이트**입니다. Apple Silicon Mac 설치본의 내장 AI가 앱의 실제 편집 도구 호출 기록으로 한 번 더 학습한 모델로 바뀌었고, 크기·메모리·속도는 이전과 같습니다.

## 바뀐 것

- **내장 AI 모델 교체**: 공개 모델 Qwen3.5-2B에 똑딱작업실 문서 편집 작업으로 만든 합성 예제 1,529개를 학습한 소형 추가 학습(LoRA)을 합쳤습니다. 추가 학습은 마지막 두 층에만 들어가고, 나머지 부분과 파일 크기(약 1.28GB)는 이전 모델과 같습니다. 학습 쪽 측정(원본 정밀도)에서 검증 손실이 0.452에서 0.267로 줄었고, 한글 합성 도구 호출 256문항 중 244문항을 맞혔습니다. 이 값은 앱 안의 4비트 모델이나 실제 파일 편집 성공률을 잰 것이 아닙니다.
- **새 버전 안내**: 예전 버전이 켜져 있는 상태에서 새 버전을 열면, 예전 창만 앞으로 나오던 대신 "새 버전이 설치되어 있습니다" 안내와 앱 종료 버튼이 뜹니다(다음 업데이트부터 적용).

## 고친 것

- 한글 문서를 열기만 하고 닫아도 "저장하지 않은 변경 사항이 있습니다"라고 묻던 문제를 고쳤습니다.
- Finder에서 문서를 열어 앱을 시작한 뒤 홈으로 가면 시작 화면이 탭 줄까지 덮어 열린 문서로 돌아갈 수 없던 문제를 고쳤습니다.
- 개발용 빌드나 임시 폴더에서 켠 앱이 터미널 명령어 `ttokttak` 연결을 가져가지 않습니다.

## 현재 범위

- 내장 AI 모델은 **Apple Silicon Mac 설치 파일에만** 들어 있습니다. Windows와 Intel Mac 설치 파일은 같은 0.16.4이지만 모델이 없어서, Claude·Codex 구독이나 API 키로 연결한 AI를 씁니다.
- 작은 모델이라 복잡한 문서에서는 지시를 놓칠 수 있습니다. 실제 수정과 저장은 각 편집기의 도구가 확인한 결과만 반영되니, 결과를 꼭 확인해 주세요.

## 설치

Apple Silicon Mac은 `arm64`, Intel Mac은 `x64`가 적힌 DMG, Windows는 `Setup` EXE를 고르세요. 서명·공증되지 않은 베타 설치본이라 처음 열 때 macOS 보안 확인이나 Windows SmartScreen 경고가 나올 수 있습니다.
