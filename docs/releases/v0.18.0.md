똑딱작업실 0.18.0은 **내장 똑딱AI를 하나로 합친 업데이트**입니다. 한글 편집·문서 작업·품의서 생성·생기부가 모두 같은 똑딱AI 하나로 돕고, 똑딱생기부도 같은 모델을 씁니다. 0.17.x에서 올라오면 생기부 어댑터 약 149MB만 새로 받고, 이미 받아 둔 기본 모델과 문서·품의 어댑터는 그대로 씁니다.

## 바뀐 것

- **똑딱AI가 하나가 됐습니다**: 공용 기본 모델(Qwen3.5-2B Q8 원본) 위에 기능별 어댑터 세 개(문서·품의·생기부)를 함께 올리고, 요청마다 그 기능의 어댑터 하나만 켭니다. 0.17.x는 생기부만 다른 모델(V7 B)을 따로 띄웠습니다.
- **생기부와 다른 기능을 오가도 기다리지 않습니다**: 모델을 바꿔 띄우지 않으므로, 생기부를 쓰다가 한글 문서 AI로 넘어가도 AI가 다시 켜지는 시간이 없습니다. 메모리도 모델 하나만큼만 씁니다.
- **받을 양이 줄었습니다**: 새로 설치하면 모델 파일 네 개(약 2.19GB)를 한 번 받습니다. 0.17.x는 약 4.1GB였습니다. 0.17.x에서 업데이트하면 생기부 어댑터(약 149MB)만 받고, 다 받아 확인한 뒤 옛 생기부 모델(약 2.08GB)을 지워 디스크 공간을 돌려받습니다. 다 받기 전에는 옛 파일을 지우지 않습니다.
- **받는 동안에도 앱은 그대로**: 진행 상황은 **설정 → AI**에 보이고, 끊기면 받던 곳부터 이어 받습니다.

## 알려진 한계

- 생기부 어댑터는 똑딱AI 생기부 V7 B의 학습 결과를 공용 기본 모델 위로 옮긴 것이라, 0.17.x의 V7 B와 답이 완전히 같지는 않습니다(모델 프로젝트 비교에서 80건 중 59건이 같았습니다). 공식 성능 심사와 교사 문체 검토는 아직 거치지 않았습니다. AI가 쓴 글은 초안이니 꼭 읽고 고쳐 주세요.
- 업데이트 뒤 생기부 어댑터를 받기 전에는 생기부 AI 쓰기가 기다립니다. 인터넷이 막힌 곳에서는 모델 릴리스의 `ddak-school-record-adapter.gguf`를 다른 곳에서 받아 **설정 → AI → [파일로 넣기]**로 넣어 주세요.
- 처음 설치하면 약 2.19GB를 받습니다(100Mbps에서 약 3분). 빈 디스크 공간이 2.5GB 이상 필요합니다.
- 웹판은 지금처럼 Gemini를 쓰고, Intel Mac 설치판에는 내장 AI가 없습니다.

## 설치

Apple Silicon Mac은 `arm64`, Intel Mac은 `x64`가 적힌 DMG, Windows는 `Setup` EXE를 고르세요. 이미 설치했다면 앱의 **업데이트 확인**으로 받을 수 있습니다. 모델 파일은 [모델 릴리스](https://github.com/ARTHONG1/ttokttak-workspace/releases/tag/model-20261120-2)에 있습니다.
