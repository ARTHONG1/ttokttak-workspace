똑딱작업실 0.17.0은 **프로그램과 내장 AI 모델을 나눈 업데이트**입니다. 설치 파일에는 앱과 AI 실행기만 들어 있고, 똑딱AI 모델 파일은 처음 쓸 때 한 번 받아 이 컴퓨터에 둡니다. 그래서 앞으로 앱을 업데이트할 때 모델을 다시 받지 않고, 모델은 줄이거나 바꾸지 않은 원본 그대로 씁니다.

## 바뀐 것

- **모델은 처음 한 번만 받습니다 (Apple Silicon Mac·Windows)**: 내장 똑딱AI를 쓰는 설치판은 처음 켤 때 모델 파일 네 개(모두 약 4.1GB)를 [모델 릴리스](https://github.com/ARTHONG1/ttokttak-workspace/releases/tag/model-20261120)에서 받습니다. 받는 동안에도 앱은 그대로 쓸 수 있고, 진행 상황은 **설정 → AI**에 보입니다. 끊기거나 앱을 꺼도 받던 곳부터 이어 받고, 인터넷이 다시 연결되거나 컴퓨터가 깨어나면 저절로 이어 갑니다. 받은 파일은 정해진 크기와 해시(SHA256)가 맞을 때만 씁니다.
- **문서 작업이 먼저 됩니다**: 한글 편집·문서 작업·품의서 생성에 쓰는 파일(약 2GB)을 먼저 받으므로, 생기부 모델을 받는 동안에도 문서 AI는 쓸 수 있습니다.
- **생기부는 V7 B 원본으로**: 0.16.14는 공용 기본 모델 위에 V7 B의 바뀐 부분을 근사해 얹었습니다. 이제 생기부의 세특·행발·창체 쓰기와 표현 바꾸기는 똑딱AI 생기부 V7 B 원본(Q8, 똑딱생기부와 같은 파일)으로 돕니다.
- **기본 모델도 원본 Q8로**: 한글 편집·문서 작업·품의서 생성은 Qwen3.5-2B Q8 원본 위에서 돕니다. 0.16.14까지는 설치 파일 크기 때문에 6비트로 줄인 기본 모델을 썼는데, 문서·품의 어댑터는 원래 Q8 위에서 학습·측정한 것입니다.
- **설치 파일이 작아졌습니다**: 모델이 빠져 설치 파일이 약 2GB에서 수백 MB로 줄었습니다.
- **폐쇄망에서는 파일로 넣기**: 인터넷이 막힌 곳에서는 모델 릴리스의 `.gguf` 파일 네 개를 다른 곳에서 받아 옮긴 뒤 **설정 → AI → [파일로 넣기]**로 넣을 수 있습니다.

## 알려진 한계

- 생기부와 다른 기능은 서로 다른 모델을 쓰므로, 둘을 번갈아 쓰면 바꿀 때마다 AI가 다시 켜지느라 몇 초 더 걸립니다. 메모리를 아끼려고 한 번에 한 모델만 띄웁니다.
- 처음 받는 데 인터넷 100Mbps에서 약 6분, 50Mbps에서 약 12분 걸립니다. 빈 디스크 공간이 4.5GB 이상 필요합니다.
- V7 B는 공식 성능 심사를 거치지 않고 개발자 결정으로 올린 모델입니다. AI가 쓴 글은 초안이니 꼭 읽고 고쳐 주세요.
- 웹판은 지금처럼 Gemini를 쓰고, Intel Mac 설치판에는 내장 AI가 없습니다.

## 설치

Apple Silicon Mac은 `arm64`, Intel Mac은 `x64`가 적힌 DMG, Windows는 `Setup` EXE를 고르세요. 이미 설치했다면 앱의 **업데이트 확인**으로 받을 수 있고, 업데이트 뒤 처음 켤 때 모델을 한 번 받습니다.
